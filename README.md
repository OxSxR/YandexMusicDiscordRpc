# YandexMusicDiscordRpc
Yandex Music Discord Rich Presence*— небольшое приложение для Windows, которое показывает текущий трек из Яндекс Музыки в профиле Discord.  Приложение работает с официальным десктопным клиентом Яндекс Музыки и с веб-версией в браузере. Оно не заменяет Яндекс Музыку и Discord, а связывает их через Windows Media Sessio
