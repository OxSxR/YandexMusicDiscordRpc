# Yandex Music RPC

**Yandex Music Discord Rich Presence** — небольшое приложение для Windows, которое показывает текущий трек из Яндекс Музыки в профиле Discord.

Приложение работает с официальным десктопным клиентом Яндекс Музыки и с веб-версией в браузере. Оно не заменяет Яндекс Музыку и Discord, а связывает их через Windows Media Session.

## Возможности

- Название трека, исполнитель и альбом.
- Обложка альбома.
- Текущая позиция и длительность трека.
- Состояние «воспроизведение» / «пауза».
- Синхронизированная шкала времени в Discord.
- Кнопки **«Открыть трек»** и **«Исполнитель»** (если ссылки найдены).
- Автоматическое определение источника: приложение или веб-версия.
- Работа в системном трее.
- Автозапуск вместе с Windows.
- Настройки Discord и источника данных.
- Автоматическое переподключение к Discord после его перезапуска.
- Один экземпляр приложения: повторный запуск открывает уже работающее окно.
- Логи и настройки хранятся в `%APPDATA%\YandexMusicDiscordRpc`.

## Требования

- Windows 10 версии 1809 или новее, либо Windows 11.
- Установленный Discord для Windows (он должен быть запущен).
- Яндекс Музыка:
  - десктопное приложение для Windows, **или**
  - веб-версия в поддерживаемом браузере.
- Для работы веб-версии браузер должен быть запущен с открытой Яндекс Музыкой.

Установленный .NET Runtime не требуется: релиз публикуется как self-contained папка. Запускайте `YandexMusicRPC.exe` из распакованной папки, не переносите один exe отдельно от остальных файлов.

## Быстрый старт

1. Распакуйте папку с релизом (или `dist\win-x64`) целиком и запустите `YandexMusicRPC.exe`.
2. Убедитесь, что Discord запущен и вы вошли в аккаунт.
3. Запустите Яндекс Музыку и включите любой трек.
4. Откройте профиль Discord — там появится активность «Слушает Яндекс Музыка».

При первом запуске включается автозапуск вместе с Windows и сворачивание в трей. Оба параметра можно изменить в настройках.

Кнопка закрытия окна сворачивает приложение в трей. Для полного выхода используйте меню значка в трее → **«Выход»**.

## Настройки

Открыть настройки можно из главного окна или из меню в трее.

### Общие

- **Запускать вместе с Windows** — добавляет приложение в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`. После переноса папки с приложением выключите и снова включите этот параметр, чтобы обновить путь в реестре.
- **Сворачивать в трей** — закрытие окна скрывает его, приложение продолжает работать.
- **Запускать свёрнутым** — при запуске окно сразу скрывается в трей (доступно, если включено сворачивание в трей).

### Discord

- **Включить Rich Presence** — главный переключатель передачи статуса.
- **Показывать обложку** — обложка альбома или иконка приложения.
- **Показывать прогресс трека** — временная шкала Discord.
- **Отображать кнопки** — ссылки на трек и исполнителя.
- **Название трека в статусе** — в строке статуса Discord отображается название песни вместо «Яндекс Музыка». Включено по умолчанию; при выключении показывается название приложения.
- **Discord Application ID** — по умолчанию используется публичное приложение «Яндекс Музыка». Можно указать собственное приложение Discord.

### Яндекс Музыка

- **Автоматически** — приоритет у активного воспроизведения; при равном состоянии выбирается десктопное приложение.
- **Веб-версия** — учитываются только браузерные сессии Яндекс Музыки.
- **Десктопное приложение** — учитывается только клиент Яндекс Музыки для Windows.
- **Загружать обложку и ссылки** — необязательные запросы к публичному каталогу Яндекс Музыки. Если каталог недоступен, приложение продолжает работать без обложки и кнопок.

## Как это работает

1. Приложение подписывается на Windows Media Session (`GlobalSystemMediaTransportControlsSessionManager`).
2. Среди медиасессий выбирается Яндекс Музыка:
   - десктопный клиент определяется по `SourceAppUserModelId`;
   - браузерная сессия проверяется по заголовку окна браузера, чтобы не принять за музыку YouTube или другой сайт.
3. Название, исполнитель, альбом, длительность, позиция и обложка читаются из медиасессии.
4. При необходимости данные дополняются через публичный поиск Яндекс Музыки: ссылка на трек, ссылка на исполнителя и обложка в высоком разрешении.
5. Информация отправляется в Discord через Rich Presence (Discord IPC).
6. При смене трека, паузе или возобновлении статус обновляется. При потере соединения приложение переподключается автоматически.

Обновления Discord ограничены одним запросом в секунду. Прогресс в Discord строится на временных метках, поэтому не требует постоянной отправки данных.

## Поддерживаемые браузеры

Определение веб-версии рассчитано на браузеры, которые создают медиасессию Windows:

- Microsoft Edge;
- Google Chrome;
- Mozilla Firefox;
- Opera и Opera GX;
- Brave;
- Vivaldi;
- Яндекс Браузер;
- Chromium.

Windows не сообщает URL вкладки браузера. Поэтому приложение проверяет заголовок окна браузера. Если Яндекс Музыка играет в **неактивной вкладке**, браузер может не передать её медиасессию в Windows, и трек не определится. В этом случае сделайте вкладку активной.

## Сборка из исходников

### Требования

- .NET SDK 8.0;
- Windows 10/11.

### Обычная сборка

```powershell
dotnet build .\src\YandexMusicDiscordRpc\YandexMusicDiscordRpc.csproj -c Release
```

Готовый файл:

```text
src\YandexMusicDiscordRpc\bin\Release\net8.0-windows10.0.19041.0\YandexMusicRPC.exe
```

### Публикация self-contained

```powershell
.\publish.ps1
```

Скрипт создаёт самодостаточную сборку в `dist\win-x64`. .NET Runtime на компьютере пользователя не нужен. Это папка с несколькими файлами: запускать нужно `YandexMusicRPC.exe` из неё, а при переносе копировать папку целиком.

Параметры:

```powershell
.\publish.ps1 -Runtime win-x64
.\publish.ps1 -FrameworkDependent
.\publish.ps1 -SingleFile
```

`-SingleFile` собирает один exe для удобства, но у такой сборки заметно выше расход памяти. Для постоянной работы рекомендуется обычная папка.

`-FrameworkDependent` создаёт компактную сборку, для которой требуется .NET Desktop Runtime 8.

Готовую папку `dist\win-x64` можно заархивировать и передать вместе с `README.md` и `LICENSE` — они уже копируются в результат публикации.

## Логи и диагностика

- Настройки: `%APPDATA%\YandexMusicDiscordRpc\settings.json`
- Лог: `%APPDATA%\YandexMusicDiscordRpc\logs\app.log`
- Архив предыдущего лога: `%APPDATA%\YandexMusicDiscordRpc\logs\app.1.log`

Лог ограничен 1 МБ и ротируется. При повреждённом `settings.json` приложение создаёт резервную копию и использует настройки по умолчанию.

Если что-то не работает:

1. Проверьте, что Discord запущен.
2. Убедитесь, что трек действительно играет в Яндекс Музыке.
3. Нажмите **«Перезапустить службу»** в главном окне.
4. Проверьте `app.log`.
5. Если не загружается обложка, проверьте доступ к `api.music.yandex.net` — VPN, прокси или блокировщик могут мешать запросу. На работу самого Rich Presence это не влияет.

## Ограничения

- Приложение не входит в аккаунт Яндекс Музыки и не получает токены. Оно читает только то, что Windows передаёт через Media Session.
- В браузере поддерживаются только сессии, которые Windows видит как медиасессию. Неактивная фоновая вкладка может не определиться.
- Одновременно отображается только один трек.
- Если Яндекс Музыка не передаёт обложку и каталог недоступен, используется иконка приложения.
- Discord показывает не более двух кнопок. Кнопки появляются только при наличии проверенных ссылок.
- Публичный каталог Яндекс Музыки является неофициальным интерфейсом и может измениться. Это не влияет на базовую работу приложения.
- Приложение не подписано цифровой подписью. SmartScreen может показать предупреждение при первом запуске.

## Производительность

- Опрос медиасессии — раз в секунду.
- Обновления Discord — не чаще одного раза в секунду; позиция передаётся через временные метки.
- Кэш обложек и метаданных ограничен.
- Логи ротируются.
- В простое приложение не выполняет тяжёлых вычислений; потребление CPU практически нулевое. При публикации папкой память составляет около 50 МБ активного private working set на тестовой машине (зависит от версии Windows, масштаба DPI и открытых окон); single-file сборка потребляет заметно больше.

## Приватность

Приложение не запрашивает пароль, не читает историю прослушивания и не отправляет телеметрию. В Discord передаются название трека, исполнитель, альбом, обложка и ссылки — в объёме, который отображается в Rich Presence. Для поиска обложки и ссылок выполняется запрос к публичному каталогу Яндекс Музыки с названием трека и исполнителем. При отключённом параметре «Загружать обложку и ссылки» запросы к каталогу не выполняются.
